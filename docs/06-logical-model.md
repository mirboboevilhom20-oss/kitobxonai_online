# 06. Модели мантиқии пойгоҳи додаҳо — Китобхонаи онлайн

## 1. Муқаддима

Модели мантиқии пойгоҳи додаҳо сохтори маълумот ва робитаи байни ҷадвалҳои системаи «Китобхонаи онлайн»-ро муайян мекунад.

Мақсади он нигоҳдорӣ, ҷустуҷӯ ва идоракунии маълумоти истифодабарандагон, китобҳо, муаллифон, категорияҳо ва китобҳои дӯстдошта мебошад.

## 2. Сохтори умумии пойгоҳи додаҳо

Пойгоҳи додаҳои система аз 6 ҷадвали асосӣ иборат аст:

1. users
2. books
3. authors
4. categories
5. book_authors
6. favorites

## 3. Тавсифи ҷадвалҳо

### 3.1. Ҷадвали users

Барои нигоҳдории маълумоти истифодабарандагон истифода мешавад.

| Майдон | Навъи маълумот | Маҳдудият |
|---|---|---|
| id | INT | PRIMARY KEY |
| first_name | VARCHAR(100) | NOT NULL |
| last_name | VARCHAR(100) | NOT NULL |
| email | VARCHAR(255) | UNIQUE, NOT NULL |
| password | VARCHAR(255) | NOT NULL |
| role | VARCHAR(20) | NOT NULL |
| created_at | DATETIME | NOT NULL |

**Вазифа:** Нигоҳдории маълумоти хонандагон ва администраторҳо.

### 3.2. Ҷадвали books

Барои нигоҳдории маълумоти китобҳо истифода мешавад.

| Майдон | Навъи маълумот | Маҳдудият |
|---|---|---|
| id | INT | PRIMARY KEY |
| title | VARCHAR(255) | NOT NULL |
| description | TEXT | NULL |
| publish_year | INT | NULL |
| cover_image | VARCHAR(255) | NULL |
| file_path | VARCHAR(255) | NULL |
| category_id | INT | FOREIGN KEY |
| created_at | DATETIME | NOT NULL |

**Вазифа:** Нигоҳдории маълумоти асосӣ ва роҳи файли электронии китоб.

### 3.3. Ҷадвали authors

Барои нигоҳдории маълумоти муаллифон истифода мешавад.

| Майдон | Навъи маълумот | Маҳдудият |
|---|---|---|
| id | INT | PRIMARY KEY |
| full_name | VARCHAR(255) | NOT NULL |
| biography | TEXT | NULL |

**Вазифа:** Нигоҳдории маълумот дар бораи муаллифони китобҳо.

### 3.4. Ҷадвали categories

Барои гурӯҳбандии китобҳо истифода мешавад.

| Майдон | Навъи маълумот | Маҳдудият |
|---|---|---|
| id | INT | PRIMARY KEY |
| name | VARCHAR(150) | UNIQUE, NOT NULL |
| description | TEXT | NULL |

**Вазифа:** Гурӯҳбандии китобҳо аз рӯйи мавзӯъ ва самт.

### 3.5. Ҷадвали book_authors

Барои муайян кардани робитаи байни китобҳо ва муаллифон истифода мешавад.

| Майдон | Навъи маълумот | Маҳдудият |
|---|---|---|
| book_id | INT | PRIMARY KEY, FOREIGN KEY |
| author_id | INT | PRIMARY KEY, FOREIGN KEY |

**Вазифа:** Пайваст кардани китобҳо бо муаллифони онҳо.

Калиди асосии ҷадвал аз ду майдон иборат аст: book_id ва author_id.

Ин ҷадвал робитаи бисёр-ба-бисёри байни китобҳо ва муаллифонро таъмин мекунад.

### 3.6. Ҷадвали favorites

Барои нигоҳдории китобҳои дӯстдоштаи истифодабарандагон истифода мешавад.

| Майдон | Навъи маълумот | Маҳдудият |
|---|---|---|
| id | INT | PRIMARY KEY |
| user_id | INT | FOREIGN KEY |
| book_id | INT | FOREIGN KEY |
| created_at | DATETIME | NOT NULL |

**Вазифа:** Нигоҳдории рӯйхати китобҳои дӯстдоштаи ҳар як хонанда.

Барои пешгирӣ кардани такрори як китоб дар рӯйхати дӯстдоштаҳои як истифодабаранда маҳдудияти UNIQUE(user_id, book_id) истифода мешавад.

## 4. Робитаҳои байни ҷадвалҳо

| № | Ҷадвали якум | Ҷадвали дуюм | Навъи робита |
|---|---|---|---|
| 1 | categories | books | One-to-Many |
| 2 | books | book_authors | One-to-Many |
| 3 | authors | book_authors | One-to-Many |
| 4 | users | favorites | One-to-Many |
| 5 | books | favorites | One-to-Many |

## 5. Калидҳои асосӣ ва хориҷӣ

### Калидҳои асосӣ (Primary Key)

Ҳар як ҷадвал барои муайян кардани сабти ягона калиди асосӣ дорад.

- users.id
- books.id
- authors.id
- categories.id
- book_authors (book_id, author_id)
- favorites.id

### Калидҳои хориҷӣ (Foreign Key)

Калидҳои хориҷӣ робитаи байни ҷадвалҳоро таъмин мекунанд.

- books.category_id → categories.id
- book_authors.book_id → books.id
- book_authors.author_id → authors.id
- favorites.user_id → users.id
- favorites.book_id → books.id

## 6. Қоидаҳои нигоҳдории маълумот

1. Ҳар як истифодабаранда бояд рақами мушаххаси ягона дошта бошад.
2. Суроғаи почтаи электронии истифодабаранда такрорнашаванда бошад.
3. Ҳар як китоб бояд ба категорияи муайян вобаста бошад.
4. Китоб метавонад як ё якчанд муаллиф дошта бошад.
5. Як муаллиф метавонад якчанд китоб навишта бошад.
6. Як хонанда метавонад якчанд китобро ба дӯстдоштаҳо илова кунад.
7. Як китоб метавонад дар рӯйхати дӯстдоштаҳои якчанд хонанда бошад.
8. Як китоб дар рӯйхати дӯстдоштаҳои як хонанда набояд такрор шавад.
9. Рамзи махфӣ бояд дар шакли хэш нигоҳ дошта шавад.
10. Ҳангоми нест кардани сабтҳо робитаҳои калидҳои хориҷӣ бояд ба назар гирифта шаванд.

## 7. Амнияти пойгоҳи додаҳо

Барои таъмини амнияти маълумот чораҳои зерин истифода мешаванд:

- Рамзҳои махфӣ дар шакли хэш нигоҳ дошта мешаванд.
- Дастрасӣ ба маълумот мувофиқи нақши истифодабаранда маҳдуд карда мешавад.
- Танҳо администратор ҳуқуқи идоракунии китобҳоро дорад.
- Маълумоти воридшаванда бояд санҷида шавад.
- Нусхаи эҳтиётии пойгоҳи додаҳо нигоҳ дошта шавад.

## 9. Хулоса

Модели мантиқии пойгоҳи додаҳо асоси нигоҳдорӣ ва идоракунии маълумоти китобхонаи онлайн мебошад.

Сохтори пешниҳодшуда имконият медиҳад, ки маълумоти китобҳо, муаллифон, категорияҳо ва истифодабарандагон ба таври муназзам нигоҳ дошта шавад.

Ин модел барои татбиқи пойгоҳи додаҳо ва таҳияи қисми серверии системаи «Китобхонаи онлайн» истифода мешавад.
