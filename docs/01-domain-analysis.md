# 01. Таҳлили соҳаи мавзӯӣ — Китобхонаи онлайн

## 1. Муқаддима

Китобхонаи онлайн низоми иттилоотие мебошад, ки барои нигоҳдорӣ, ҷустуҷӯ, идоракунӣ ва истифодаи китобҳои электронӣ тавассути интернет пешбинӣ шудааст.

Мақсади асосии лоиҳа рақамӣ гардонидани фаъолияти китобхона ва фароҳам овардани дастрасии осон ба захираи китобҳо мебошад.

## 2. Тавсифи соҳаи мавзӯӣ

Дар китобхонаи анъанавӣ хонанда барои пайдо кардани китоб бояд ба китобхона муроҷиат кунад. Дар низоми онлайн истифодабаранда метавонад тавассути сомона китобро ҷустуҷӯ намуда, маълумоти онро омӯзад ва дар ҳолати дастрас будан онро мутолиа кунад.

Система маълумотро дар бораи китобҳо, муаллифон, категорияҳо ва истифодабарандагон нигоҳ медорад.

## 3. Мақсади таҳияи система

- Таъмини дастрасии онлайн ба китобҳо.
- Содда кардани ҷустуҷӯи китобҳо.
- Нигоҳдорӣ ва идоракунии маълумоти китобҳо.
- Кам кардани кори дастии кормандони китобхона.
- Баланд бардоштани сифати хизматрасонии китобхона.

## 4. Иштирокчиёни асосии система

### 4.1. Меҳмон

Меҳмон шахсе мебошад, ки ба сомона бе ворид шудан ба ҳисоби шахсӣ ташриф меорад.

Имкониятҳо:
- Дидани рӯйхати китобҳо.
- Ҷустуҷӯи китобҳо.
- Дидани маълумоти китоб.
- Сабти ном дар система.

### 4.2. Хонанда

Хонанда истифодабарандаи сабтиномшудаи система мебошад.

Имкониятҳо:
- Ворид шудан ба ҳисоби шахсӣ.
- Ҷустуҷӯи китобҳо.
- Дидани маълумоти муфассали китоб.
- Мутолиаи китобҳои электронии дастрас.
- Илова кардани китоб ба рӯйхати дӯстдоштаҳо.
- Идоракунии профили шахсӣ.

### 4.3. Администратор

Администратор шахси масъули идоракунии система мебошад.

Имкониятҳо:
- Илова кардани китоб.
- Таҳрир кардани маълумоти китоб.
- Нест кардани китоб.
- Идоракунии категорияҳо.
- Дидани истифодабарандагон.
- Идоракунии маълумоти система.

## 5. Объектҳои асосии соҳаи мавзӯӣ

### 5.1. Истифодабаранда (User)

Маълумоти шахсони сабтиномшуда дар система нигоҳ дошта мешавад.

Хусусиятҳо:
- Рақами мушаххас (ID).
- Ном.
- Насаб.
- Суроғаи почтаи электронӣ.
- Рамзи махфӣ.
- Нақши истифодабаранда.
- Санаи сабти ном.

### 5.2. Китоб (Book)

Китоб объекти асосии система мебошад.

Хусусиятҳо:
- Рақами мушаххас (ID).
- Номи китоб.
- Муаллиф.
- Тавсифи китоб.
- Категория.
- Соли нашр.
- Сурати муқова.
- Файли электронӣ.
- Санаи илова шудан.

### 5.3. Муаллиф (Author)

Муаллиф шахсест, ки китобро эҷод кардааст.

Хусусиятҳо:
- Рақами мушаххас (ID).
- Ном ва насаб.
- Маълумоти мухтасар.

### 5.4. Категория (Category)

Категория барои гурӯҳбандии китобҳо истифода мешавад.

Хусусиятҳо:
- Рақами мушаххас (ID).
- Номи категория.
- Тавсифи категория.

### 5.5. Китобҳои дӯстдошта (Favorite)

Ин объект барои нигоҳ доштани рӯйхати китобҳои дӯстдоштаи хонанда истифода мешавад.

Хусусиятҳо:
- Рақами мушаххас (ID).
- ID-и истифодабаранда.
- ID-и китоб.
- Санаи илова шудан.

## 6. Робитаҳои байни объектҳо

- Як муаллиф метавонад якчанд китоб дошта бошад.
- Ҳар як китоб ба як ё якчанд муаллиф тааллуқ дошта метавонад.
- Як категория метавонад якчанд китобро дар бар гирад.
- Ҳар як китоб ба категорияи муайян тааллуқ дорад.
- Як истифодабаранда метавонад якчанд китобро ба дӯстдоштаҳо илова кунад.
- Як китоб метавонад дар рӯйхати дӯстдоштаҳои якчанд истифодабаранда бошад.

## 7. Равандҳои асосии бизнес

### 7.1. Сабти ном

1. Истифодабаранда сомонаро мекушояд.
2. Қисми сабти номро интихоб мекунад.
3. Маълумоти заруриро ворид мекунад.
4. Система дурустии маълумотро месанҷад.
5. Ҳисоби истифодабаранда сохта мешавад.

### 7.2. Ҷустуҷӯи китоб

1. Истифодабаранда ба саҳифаи китобҳо мегузарад.
2. Номи китоб ё муаллифро ворид мекунад.
3. Система китобҳои мувофиқро меёбад.
4. Натиҷаҳо ба истифодабаранда нишон дода мешаванд.

### 7.3. Мутолиаи китоб

1. Хонанда ба ҳисоби худ ворид мешавад.
2. Китоби дилхоҳро интихоб мекунад.
3. Маълумоти китобро мебинад.
4. Агар файли электронӣ дастрас бошад, онро мекушояд.
5. Китобро мутолиа мекунад.

### 7.4. Идоракунии китобҳо

1. Администратор ба панели идоракунӣ ворид мешавад.
2. Қисми идоракунии китобҳоро мекушояд.
3. Китоби нав илова мекунад ё маълумоти китобро таҳрир менамояд.
4. Система тағйиротро нигоҳ медорад.

## 8. Қоидаҳои бизнес

1. Ҳар як истифодабаранда бояд ID-и ягона дошта бошад.
2. Суроғаи почтаи электронӣ бояд такрорнашаванда бошад.
3. Танҳо администратор ҳуқуқи илова, таҳрир ва нест кардани китобҳоро дорад.
4. Китоб бояд ба категорияи муайян вобаста бошад.
5. Як истифодабаранда наметавонад як китобро дар рӯйхати дӯстдоштаҳо ду маротиба илова кунад.
6. Рамзҳои махфӣ бояд дар шакли ҳифзшуда нигоҳ дошта шаванд.
7. Файли китоб танҳо дар ҳолати мавҷуд буданаш барои мутолиа дастрас мешавад.

## 9. Маҳдудиятҳои система

- Дастрасӣ ба функсияҳои шахсӣ танҳо баъд аз воридшавӣ имконпазир аст.
- Идоракунии китобҳо танҳо ба администратор иҷозат дода мешавад.
- Мутолиаи китоб аз мавҷудияти файли электронӣ вобаста аст.
- Система бояд маълумоти истифодабарандагонро ҳифз намояд.

## 10. Хулоса

Таҳлили соҳаи мавзӯӣ нишон медиҳад, ки китобхонаи онлайн бояд дорои имкониятҳои ҷустуҷӯ, намоиш, мутолиа ва идоракунии китобҳо бошад.

Объектҳои асосии система истифодабаранда, китоб, муаллиф, категория ва китобҳои дӯстдошта мебошанд. Ин объектҳо барои тарҳрезии сохтори пойгоҳи додаҳо ва таҳияи диаграммаҳои низом истифода мешаванд.
