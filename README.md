# Китобхонаи онлайн

## 1. Маълумоти умумӣ

**Номи лоиҳа:** Китобхонаи онлайн (Online Library)

**Навъи система:** Системаи идоракунии китобхонаи электронӣ.

**Забони лоиҳа:** Тоҷикӣ.

## 2. Мақсади лоиҳа

Мақсади асосии лоиҳа сохтани системаи онлайн барои ҷустуҷӯ, дидан, идоракунӣ ва истифодаи китобҳои электронӣ мебошад.

Система ба хонандагон имкон медиҳад, ки китобҳои заруриро зуд пайдо кунанд ва аз хизматрасониҳои китобхона истифода баранд.

## 3. Вазифаҳои асосӣ

- Бақайдгирӣ ва воридшавии истифодабарандагон.
- Ҷустуҷӯи китобҳо аз рӯйи ном ва муаллиф.
- Гурӯҳбандии китобҳо аз рӯйи категория.
- Дидани маълумоти пурраи китоб.
- Илова кардани китоб ба рӯйхати дӯстдоштаҳо.
- Идоракунии китобҳо аз ҷониби маъмур.
- Идоракунии истифодабарандагон.
- Назорати ҳолати китобҳо ва дархостҳо.

## 4. Иштирокчиёни система

1. **Меҳмон** — метавонад китобҳоро бинад ва ҷустуҷӯ кунад.
2. **Хонанда** — метавонад бақайдгирӣ кунад, ворид шавад ва аз имкониятҳои китобхона истифода барад.
3. **Маъмур (Admin)** — китобҳо, категорияҳо ва истифодабарандагонро идора мекунад.

## 5. Функсияҳои система

### Барои хонанда
- Бақайдгирӣ.
- Воридшавӣ.
- Ҷустуҷӯи китоб.
- Дидани маълумоти китоб.
- Илова ба дӯстдоштаҳо.
- Ирсоли дархости гирифтани китоб.
- Дидани таърихи дархостҳо.

### Барои маъмур
- Илова кардани китоб.
- Таҳрири маълумоти китоб.
- Нест кардани китоб.
- Идоракунии категорияҳо.
- Идоракунии истифодабарандагон.
- Баррасии дархостҳои хонандагон.

## 6. Ҳуҷҷатҳои лоиҳа

Дар ин папка ҳуҷҷатҳои техникии система нигоҳ дошта мешаванд:

- Талаботи функсионалӣ ва ғайрифунксионалӣ.
- Тавсифи меъмории система.
- Тарҳи пойгоҳи додаҳо.
- Диаграммаҳои UML.
- Сенарияҳои истифода.
- Тавсифи равандҳои корӣ.

## 7. Натиҷаи интизоршаванда

Дар натиҷаи иҷрои лоиҳа системаи мукаммали китобхонаи онлайн сохта мешавад, ки истифодаи китобҳоро осон намуда, идоракунии фаъолияти китобхонаро автоматӣ мегардонад.
